# Asset map

Every image on the site, where it comes from in the print creative, and how it's used.
All web files are WebP, generated by `scripts/build_assets.py` into `public/images/`.

**Page numbers** are the printed folios. The supplied PDF is 19 PDF pages, but each PDF page is a cropped *spread*: the right-hand page sits outside the page box. The script and this map read the full spreads.
